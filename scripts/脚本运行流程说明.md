## 八、常见问题

### 8.1 模块导入错误

**问题**：`ModuleNotFoundError: No module named 'utils_公共函数'`

**解决**：确保在脚本目录下运行：
```bash
cd /mnt/e/博士毕业论文/大论文/论文撰写/统计分析/脚本
python3 脚本名.py
```

### 8.2 中文字体显示问题

**问题**：图表中文字显示为方框

**解决**：脚本已内置字体自动检测，若仍有问题可手动指定：
```python
# 在 utils_公共函数.py 中修改 setup_chinese_font() 函数
# 指定系统中可用的中文字体路径
```

### 8.3 数据文件未找到

**问题**：`FileNotFoundError: CFMC_5989.json`

**解决**：确认数据文件存在于：
```
/mnt/e/博士毕业论文/大论文/论文撰写/统计分析/语料_输入/CFMC_5989.json
```

### 8.4 SEM模型收敛问题

**问题**：`semopy` 模型未收敛或拟合失败

**解决**：
- 检查数据是否有缺失值
- 尝试调整优化器参数
- 查看Q3_02输出的模型诊断信息

### 8.5 脚本超时

**问题**：使用批量运行工具时提示"脚本执行超时"

**解决**：
- 默认超时时间为10分钟
- 若需更长时间，可在脚本中修改`timeout`参数
- 或单独运行该脚本
