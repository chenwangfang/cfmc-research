# 概念复杂度和认知通达度快速取值手册

> **适用范围**：CFMC_5989.json语料标注
> **版本**：1.1
> **更新日期**：2026-05-08

## 一、快速判定流程图

### 1.1 认知通达度(CA)判定流程

```
源域类型是什么？
    │
    ├─ 身体/空间/感官 ──────────────────→ CA = 5
    │
    ├─ 常见物体/食物/动物 ─────────────→ CA = 4-5
    │
    ├─ 专业领域（经济/军事/机械）────→ CA = 3-4
    │
    ├─ 抽象关系/复杂系统 ─────────────→ CA = 2-3
    │
    └─ 罕见/生僻/需专业知识 ──────────→ CA = 1-2
```

### 1.2 概念复杂度(CC)判定流程

```
映射方向(MD)是什么？
    │
    ├─ MD=1（具→具）────→ CC = 1-2
    │
    ├─ MD=2（具→抽）────→ CC = 1-2（默认）
    │   └─ 目标域高度抽象 → CC = 3
    │
    ├─ MD=3（抽→抽）────→ CC = 3-4
    │
    └─ MD=4（抽→具）────→ CC = 4
```

## 二、核心约束：CA与CC负相关

**一般规律**：认知通达度与概念复杂度呈负相关

| CA值 | 典型CC值 | 说明 |
|:----:|:--------:|:-----|
| 5 | 1-2 | 源域极易激活，目标域简单 |
| 4 | 2 | 源域易激活，目标域较简单 |
| 3 | 2-3 | 源域中等，目标域中等 |
| 2 | 3-4 | 源域较难，目标域较复杂 |
| 1 | 4 | 源域极难，目标域极复杂 |

**交叉验证规则**：若CA+CC > 7 或 CA+CC < 4，需复核取值合理性。

## 五、实际分布参考

基于CFMC_5989.json当前发布语料库的分布，语料总体集中在中高CA和中低CC区间，但映射方向并不以MD=2单独占优：

| 维度 | 主要分布 | 占比/说明 |
|:-----|:---------|:----:|
| CA | 4-5级 | 68.45% |
| CC | 2级 | 50.73% |
| MD | MD=3（抽→抽）最高，MD=1与MD=2接近 | MD=3/1/2/4依次为33.41%/28.15%/25.94%/12.49% |

**实用启示**：遇到不确定的情况，CA取4、CC取2可作为初始参照，但映射方向必须按源域和目标域的语义角色与具体/抽象属性判定，不应预设MD=2为默认方向。

## 六、边界案例处理

### 6.1 五条快速处理原则

1. **负相关原则**：CA高则CC低，CA低则CC高；若不符合，需复核
2. **映射方向参照**：MD提供初步构型参照，CC仍按目标域负荷与映射整合成本综合判断
3. **源域优先**：CA主要看源域的日常性，目标域影响较小
4. **默认中值**：模糊时取CA=4、CC=2
5. **极端值谨慎**：CA=1或CC=4需有明确依据

### 6.2 常见边界情况

| 情况 | 处理方式 |
|:-----|:---------|
| 源域是专业术语但目标域日常 | CA适当降低，CC保持MD默认值 |
| 隐喻高度规约化（死隐喻） | CA上调至4-5 |
| 新奇隐喻（创新表达） | CA下调1级 |
| 文化特异性隐喻 | 按目标读者熟悉度判定CA |

## 八、快速核验清单

标注完成后，检查以下项目：

- [ ] CA + CC 在4-7范围内（负相关验证）
- [ ] CC与MD对应（MD=1→CC=1-2, MD=2→CC=1-2, MD=3→CC=3-4, MD=4→CC=4）
- [ ] CA=5仅用于身体/空间/感官等核心源域
- [ ] CA=1-2仅用于确实生僻的专业概念
- [ ] CC=4仅用于MD=4或极抽象目标域
