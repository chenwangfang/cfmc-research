# 标注阶段连续变量ICC计算

> **验证目的**：评估标注者间对连续变量标注的一致性
> **数据来源**：双盲标注数据_1200条.csv
> **判断标准**：*ICC*(2,1)≥0.78

## 1 ICC模型选择

### 1.1 模型类型

采用**ICC(2,1)**模型，即：
- **双向随机效应**：标注员视为随机样本
- **单一测量**：每名标注员对每条语料评分一次

### 1.2 选择依据

根据Shrout & Fleiss (1979)：
- 本研究的标注员可视为随机抽取的评分者群体的代表
- 研究结论需推广到其他潜在标注员
- 因此选择"双向随机效应"模型

## 2 计算公式

### 2.1 ICC(2,1)公式

$$ICC(2,1) = \frac{MS_R - MS_E}{MS_R + (k-1)MS_E + \frac{k}{n}(MS_C - MS_E)}$$

其中：
- $MS_R$：行均方 (被试间变异)
- $MS_C$：列均方 (评分者间变异)
- $MS_E$：误差均方
- $k$：评分者数量 (k=2)
- $n$：被试数量 (n=1200)

### 2.2 计算示例

以`cognitive_accessibility`字段为例：

| 变异来源 | SS | df | MS |
|:---------|:---|:---|:---|
| 行 (被试) | - | 1199 | 1.522 |
| 列 (评分者) | - | 1 | 0.023 |
| 误差 | - | 1199 | 0.015 |
| 总计 | - | 2399 | - |

$$ICC(2,1) = \frac{1.522 - 0.015}{1.522 + 0.015 + \frac{2}{1200}(0.023 - 0.015)} = 0.981$$
