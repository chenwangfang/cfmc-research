# 培训阶段信度计算

> **验证目的**：确认培训效果，建立标注的理论一致性
> **数据来源**：试标注数据_100条.csv
> **判断标准**：初始一致性*κ*≥0.70



## 1 验证背景

培训阶段为期20小时，培训内容涵盖：

- Sullivan自主-依存原则的操作化判断 (8小时)
- Langacker认知参照点的识别方法 (6小时)
- Goldberg四类链接关系的区分标准 (6小时)

培训结束后，两名标注员独立标注100条试标注语料，计算初始一致性。



## 2 数据说明

### 2.1 试标注语料抽样

100条试标注语料用于培训后的规则校准，采用平衡复核思路，尽量让不同语体和疑难情形进入训练环节。该样本不按5,971条发布标注记录的自然语体比例解释，也不用于估计各语体的总体分布：

| 语体类型 | 复核目标 |
|:---------|:---------|
| 文学 | 纳入常见书面语样本 |
| 新闻 | 纳入常见书面语样本 |
| 学术 | 提高低频语体在训练中的可见度 |
| 网络 | 纳入非正式书面语样本 |
| 对话 | 提高低频语体和边界用法在训练中的可见度 |

### 2.2 标注字段

试标注涵盖CFMC-33全部33个核心字段，其中：
- 分类变量：17个
- 连续变量：16个



## 3 计算方法

### 3.1 Cohen's Kappa计算公式

$$\kappa = \frac{P_o - P_e}{1 - P_e}$$

其中：
- $P_o$ = 观察一致率 = 两名标注员标注一致的比例
- $P_e$ = 期望一致率 = 随机情况下的预期一致概率

### 3.2 计算示例

以`construction_type`字段为例：

| 统计项 | 数值 |
|:-------|:-----|
| 总标注数 (N) | 100 |
| 一致数 | 82 |
| 观察一致率 ($P_o$) | 0.82 |
| 期望一致率 ($P_e$) | 0.083 (12类均匀分布) |
| Cohen's *κ* | (0.82 - 0.083) / (1 - 0.083) = **0.804** |

## 5 参考标准
