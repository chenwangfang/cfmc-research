## 附录C 认知通达度的构念界定与测量方案

### 1 认知通达度的构念界定

#### 1.1 核心概念界定

参考Sullivan (2013: 104-110) 对隐喻构式通达性和Langacker (1987: 59-60) 对认知固化的阐述，本研究将**认知通达度** (Cognitive Accessibility, CA) 界定为：源域概念在认知系统中被激活的容易程度。这一维度测量源域的认知特征——当说话者选择特定源域来表达隐喻时，该源域概念从长时记忆中被提取并激活的认知便利性。认知通达度具体通过**认知域规约化程度** ($D_{reg}$) 与**映射关联透明度** ($D_{trans}$) 两个核心子维度加以测量，并以**语境支持程度** ($D_{context}$) 作为调节变量。

#### 1.2 测量框架的理论基础

认知通达度的理论基础来自两个相互补充的研究传统。

**理论传统一：认知固化概念**

Langacker (1987: 59-60; 2008: 220-235) 提出的认知固化 (entrenchment) 概念揭示了语言单位从临时建构到认知固化的连续过程：高频使用导致认知单位在神经网络中形成稳定的激活模式，激活所需的认知资源逐渐减少，最终成为认知系统中可自动提取的常规单位。

**理论传统二：规约化隐喻理论**

Lakoff & Johnson (1980: 139-146) 区分的规约化隐喻 (conventional metaphors) 与创新隐喻 (novel metaphors) 揭示了隐喻在规约化程度上的连续分布：规约化隐喻如"时间是金钱"经过长期使用已成为概念系统的固化部分，其认知加工高度自动化；创新隐喻如"意识是全息图"则需要调用更多认知资源进行在线建构。

#### 1.3 测量框架：两个核心子维度与一个调节变量

基于上述理论基础，本研究建立认知通达度的测量框架。该框架包含两个核心子维度和一个调节变量。

##### 维度一：认知域规约化程度 ($D_{reg}$)

**理论定位**：核心子维度，在综合模型中权重为0.55，测量源域概念在个体认知系统和文化共享知识中的固化水平

**理论基础**：Langacker (1987: 59-60; 2008: 220-235) 的认知固化理论与Lakoff & Johnson (1980: 139-146) 的规约化隐喻理论

认知域规约化程度反映源域概念在认知系统中的固化强度。根据Langacker (1987: 59-60) 的认知固化概念，语言单位的规约化取决于使用频率：高频使用的结构在认知系统中形成稳固的认知路径 (cognitive routine)，激活所需的认知努力较少。在系表隐喻构式中，规约化程度体现在两个层面：

1. **词汇层规约化**：根据Sullivan (2013: 104-110) 的自主—依存原则，主语NP₁编码目标域 (依存成分)，表语NP₂编码源域 (自主成分)。源域词汇 (表语) 的词频反映了该概念在心理词库中的通达度

2. **结构层规约化**：源域在隐喻构式中的出现频率反映了构式固化度，文化共享度则测量源域概念在目标文化中的普及程度 (Schmid, 2007)

**操作指标**：词汇固化度 ($L_{entrench}$)、构式固化度 ($C_{entrench}$)、文化共享度 ($Cul_{share}$)

**认知机制**：规约化程度越高，认知单位的固化程度越强，激活所需的认知努力越少

##### 维度二：映射关联透明度 ($D_{trans}$)

**理论定位**：核心子维度，在综合模型中权重为0.45，测量源域与目标域之间关联的认知可见性

**理论基础**：Sullivan (2013: 104-110) 的自主—依存原则 (autonomous-dependent principle)

映射关联透明度反映源域到目标域的映射路径的直接性与清晰度。Sullivan (2013: 104-110) 指出，题元隐喻构式的映射关联透明度取决于自主成分 (源域/表语NP₂) 到依存成分 (目标域/主语NP₁) 的结构投射复杂度。映射关联透明度具体体现在两个方面：

1. **语义关联性**：源域与目标域在概念空间中的语义距离越近，映射路径越直接，认知加工越容易

2. **映射系统性**：源域结构与目标域结构的对应程度越高，映射越系统化，理解越透明

**操作指标**：语义距离 ($Sem_{dist}$)、映射对应度 ($Map_{corr}$)

**认知机制**：源域与目标域的语义关联越强、映射对应越系统，自主—依存关系越透明，认知通达度越高

##### 调节变量：语境支持程度 ($D_{context}$)

**理论定位**：调节变量，测量具体语境对源域激活的辅助作用。语境支持程度不直接构成认知通达度的核心成分，而是在具体用法事件中调节核心维度的可及性

**理论基础**：Langacker (2008: 457-491) 的用法事件 (usage event) 理论

语境支持程度反映具体用法事件中语境线索对构式加工的促进或阻碍作用。Langacker (2008: 457-491) 指出，构式例示的实际使用需要在用法事件中实现，而语境在此过程中提供关键的认知支架 (cognitive scaffolding)。语境支持体现在：

1. **语义层支持**：共现语言成分 (修饰语、状语等) 与构式的语义关联度，可通过词向量相似度量化

2. **语用层支持**：整体语境对隐喻意图的透明程度，反映认知主体无需额外推理即可理解构式的容易度

**操作指标**：语境线索强度 ($Con_{cue}$，基于词向量余弦相似度)、体裁依赖度 ($Gen_{dep}$，人工评分)

**认知机制**：在具体用法事件中，语境线索可以放大或抑制核心维度的可及性。高语境支持放大通达度，低语境支持抑制通达度

### 2 认知通达度测量方案

#### 2.1 总体框架

##### 2.1.1 理论-测量对应关系

| 理论构念 | 测量维度 | 操作指标 | 数据来源 | 测量方法 |
|:--------|:--------|:--------|:--------|:--------|
| 认知域规约化程度 | 核心维度一：$D_{reg}$ | 词汇固化度+构式固化度+文化共享度 | BCC语料库+人工评分 | 自动+人工 |
| 映射关联透明度 | 核心维度二：$D_{trans}$ | 语义距离+映射对应度 | 词向量+人工评分 | 半自动+人工 |
| 语境支持程度 | 调节变量：$D_{context}$ | 语境线索强度+体裁依赖度 | 标注数据+词向量 | 半自动+人工 |

#### 2.2 维度一：认知域规约化程度($D_{reg}$)的测量

##### 2.2.1 理论依据

**Langacker (2008: 220-235) 的entrenchment量化原则**：
- 单位的固化程度正比于使用频率(token frequency)
- 图式的固化程度正比于类型频率(type frequency)
- 文化共享度反映概念在目标文化中的普及程度 (Schmid, 2007)

##### 2.2.2 指标1：词汇固化度($L_{entrench}$)

**定义**：源域表达的词频与搭配频率，测量源域词汇在心理词库中的固化程度。

**计算公式**：

$$L_{entrench} = \frac{\log_{10}(f_{source} + 1)}{\log_{10}(f_{max} + 1)}$$

其中：
- $f_{source}$ = 源域表达 (表语) 在BCC语料库中的总频次
- $f_{max}$ = 语料库中最高频词的频次
- 加1平滑处理，避免log(0)

**$f_{max}$的确定方法**：
1. 从BCC语料库词频表提取最高频词（通常为功能词"的"）
2. 查询该词的总频次
3. 参考值：BCC语料库 (150亿字规模) 中"的"约为5亿次，即$f_{max} \approx 500,000,000$

**理论依据**：对数转换符合Zipf定律 (Zipf, 1949)，反映词频与认知通达度的非线性关系

**数据来源**：BCC语料库词频表 (150亿字规模)

**标准化范围**：[0, 1]

**Python实现示例**：

```python
import math

def calculate_L_entrench(f_source, f_max):
    """
    计算词汇固化度 L_entrench
    
    参数:
        f_source: 源域表达(表语)在BCC语料库中的总频次
        f_max: 语料库中最高频词的频次(如"的"约5亿次)
    
    返回:
        L_entrench: 词汇固化度，范围[0, 1]
    """
    L_entrench = math.log10(f_source + 1) / math.log10(f_max + 1)
    return round(L_entrench, 4)

## 示例：计算"金钱"的词汇固化度
## 假设"金钱"在BCC中频次为500万，最高频词频次为5亿
L_entrench = calculate_L_entrench(5000000, 500000000)
print(f"金钱的词汇固化度: {L_entrench}")  # 输出约0.77
```

##### 2.2.3 指标2：构式固化度($C_{entrench}$)

**定义**：源域在隐喻构式中的出现频率，测量该源域用于隐喻映射的频繁程度。

**计算公式**：

$$C_{entrench} = \frac{\log_{10}(f_{metaphor} + 1)}{\log_{10}(f_{max\_metaphor} + 1)}$$

其中：
- $f_{metaphor}$ = 该源域在系表隐喻构式中的出现频次
- $f_{max\_metaphor}$ = 语料库中最高频隐喻源域的频次

**$f_{max\_metaphor}$的确定方法**：
1. 对CFMC-5989语料库中的表语 (源域) 进行分类统计
2. 计算每个源域类型的出现频次
3. 取最高频源域的频次作为$f_{max\_metaphor}$
4. 参考值：根据CFMC语料库统计，最高频源域约800-1000次

**数据来源**：CFMC-5989语料库

**标准化范围**：[0, 1]

**Python代码示例**：

```python
import math

def calculate_C_entrench(f_metaphor, f_max_metaphor):
    """
    计算构式固化度 C_entrench
    
    参数:
        f_metaphor: 源域在系表隐喻构式中的出现频次
        f_max_metaphor: 语料库中最高频隐喻源域的频次
    
    返回:
        C_entrench: 构式固化度 [0, 1]
    
    示例:
        >>> C_entrench = calculate_C_entrench(150, 800)
        >>> print(C_entrench)  # 输出: 0.7520
    """
    C_entrench = math.log10(f_metaphor + 1) / math.log10(f_max_metaphor + 1)
    return round(C_entrench, 4)

## 使用示例
## 假设"金钱"在CFMC语料库的隐喻构式中出现150次，最高频源域出现800次
C_entrench = calculate_C_entrench(150, 800)
print(f"金钱的构式固化度: {C_entrench}")  # 输出约0.75
```

##### 2.2.4 指标3：文化共享度($Cul_{share}$)

**定义**：源域概念在目标文化中的普及程度，测量该概念是否属于文化共享知识。

**评分标准**：5级量表

| 等级 | 得分 | 判断标准 | 典型示例 |
|:----|:-----|:--------|:--------|
| 5 | 1.00 | 基本身体经验、普遍文化常识 | 金钱、旅程、道路 |
| 4 | 0.80 | 常见具体概念、广泛文化认知 | 火焰、建筑、战场 |
| 3 | 0.60 | 中等专业程度、较广泛认知 | 蓝图、配方、机器 |
| 2 | 0.40 | 专业领域概念、有限文化认知 | 算法、基因、光谱 |
| 1 | 0.20 | 高度专业或新创概念 | 全息图、量子态、织物(物理学义) |

**评分实施**：双人独立评分，取平均值

**标准化范围**：[0, 1]

##### 2.2.5 维度一综合得分

**计算公式**(对齐论文正文公式3-2)：

$$D_{reg} = 0.4 \times L_{entrench} + 0.4 \times C_{entrench} + 0.2 \times Cul_{share}\quad\quad\text{(3-2)}$$

**权重分配的理论依据**：

- $w_1 = 0.4$(词汇固化度)：源域词汇的词频直接反映其在心理词库中的固化程度，是认知通达度的核心指标

- $w_2 = 0.4$(构式固化度)：源域在隐喻构式中的使用频率反映其作为隐喻源域的规约化程度，同等重要

- $w_3 = 0.2$(文化共享度)：作为调节因素，反映概念在文化层面的普及程度 (Schmid, 2007)

**得分范围**：[0, 1]

**评分标准**(对应论文正文表3-19)：

| 等级 | 得分范围 | 等级名称 | 特征描述 | 典型示例 |
|:-----|:---------|:---------|:---------|:---------|
| 5级 | 0.80-1.00 | 极高通达 | 身体经验、基本空间、高频规约隐喻 | "时间是金钱""人生是旅程" |
| 4级 | 0.60-0.79 | 高通达 | 常见具象域、中高频隐喻 | "爱情是火焰""思想是食物" |
| 3级 | 0.40-0.59 | 中等通达 | 专业领域、中频隐喻 | "理论是建筑""市场是战场" |
| 2级 | 0.20-0.39 | 低通达 | 技术领域、低频隐喻 | "基因是蓝图""算法是配方" |
| 1级 | 0.00-0.19 | 极低通达 | 新创隐喻、跨文化罕见 | "意识是全息图""时空是织物" |

**效度预测**：

预期分布(基于5级量表归并为3级)：
- 高规约化($D_{reg}$ ≥ 0.60，对应4-5级)：约30%
- 中规约化(0.40 ≤ $D_{reg}$ < 0.60，对应3级)：约40%
- 低规约化($D_{reg}$ < 0.40，对应1-2级)：约30%

验证方法：
- 与专家评分的相关性：*r* ≥ 0.60
- 与构式使用频率的相关性：*r* ≥ 0.50

#### 2.3 维度二：映射关联透明度($D_{trans}$)的测量

##### 2.3.1 理论依据

**Sullivan (2013: 104-110) 的autonomous-dependent mapping理论**：

映射关联透明度反映源域与目标域之间关联的认知可见性。Sullivan (2013: 104-110) 指出，题元隐喻构式的映射关联透明度取决于自主成分(源域/表语NP₂)到依存成分(目标域/主语NP₁)的结构投射复杂度。映射关联透明度包含两个子指标：语义距离和映射对应度。

##### 2.3.2 指标1：语义距离($Sem_{dist}$)

**定义**：源域与目标域在概念空间中的相似度，测量两个概念域之间的语义关联程度。

**计算方法**：使用预训练词向量模型计算源域与目标域的余弦相似度

$$Sem_{dist} = \frac{1 + \cos(\vec{v}_{source}, \vec{v}_{target})}{2}$$

其中：
- $\vec{v}_{source}$ = 源域(表语)的词向量表示
- $\vec{v}_{target}$ = 目标域(主语)的词向量表示
- 归一化到[0, 1]范围

**词向量模型**：Tencent AI Lab中文词向量(800万词，200维)

**理论依据**：语义距离越近，映射路径越直接，认知加工越容易

**特殊处理**：
- 短语：取中心词向量
- OOV词：使用字向量平均或赋予语料库平均相似度(约0.35)

**标准化范围**：[0, 1]

**Python实现示例**：

```python
from gensim.models import KeyedVectors
import numpy as np

## 加载Tencent AI Lab中文词向量(首次运行需下载)
## 下载地址：https://ai.tencent.com/ailab/nlp/zh/embedding.html
def load_word_vectors(path="Tencent_AILab_ChineseEmbedding.txt"):
    """加载预训练词向量模型"""
    model = KeyedVectors.load_word2vec_format(path, binary=False)
    return model

def calculate_Sem_dist(model, source_word, target_word):
    """
    计算语义距离 Sem_dist
    
    参数:
        model: 词向量模型
        source_word: 源域词(表语)
        target_word: 目标域词(主语)
    
    返回:
        Sem_dist: 语义距离，范围[0, 1]
    """
    try:
        cos_sim = model.similarity(source_word, target_word)
        Sem_dist = (1 + cos_sim) / 2  # 归一化到[0, 1]
        return round(Sem_dist, 4)
    except KeyError:
        # OOV处理：返回语料库平均相似度
        return 0.35

## 示例用法
## model = load_word_vectors()
## Sem_dist = calculate_Sem_dist(model, "金钱", "时间")
## print(f"'时间-金钱'语义距离: {Sem_dist}")
```

##### 2.3.3 指标2：映射对应度($Map_{corr}$)

**定义**：源域结构与目标域结构的系统对应程度，测量跨域映射的规则性。

**评分标准**：5级量表

| 等级 | 得分 | 判断标准 | 操作化指标 | 典型示例 |
|:----|:-----|:--------|:----------|:--------|
| 5 | 1.00 | 完全系统对应 | ≥3个映射维度可识别 | 时间是金钱 (花费、节省、浪费) |
| 4 | 0.80 | 较系统对应 | 2-3个映射维度可识别 | 人生是旅程 (起点、终点、道路) |
| 3 | 0.60 | 部分对应 | 1-2个映射维度可识别 | 爱情是火焰 (热度、燃烧)；理论是建筑 (结构、支撑) |
| 2 | 0.40 | 有限对应 | 仅1个映射维度可识别 | 音乐是语言 (表达) |
| 1 | 0.20 | 弱对应 | 无明确映射维度可识别 | 新创隐喻 |

**映射维度判定说明**：
- "映射维度"指源域结构元素向目标域的系统投射
- 常见映射维度类型：动作映射 (如"花费/节省")、属性映射 (如"热/冷")、关系映射 (如"起点-终点")、实体映射 (如"道路/障碍")
- 评分时应列出可识别的具体映射维度，根据维度数量确定等级

**评分实施**：
1. 双人独立评分
2. 计算一致性：Cohen's *κ* ≥ 0.70
3. 分歧案例讨论或第三人仲裁

**标准化范围**：[0, 1]

##### 2.3.4 维度二综合得分

**计算公式**(对齐论文正文公式3-3)：

$$D_{trans} = 0.5 \times Sem_{dist} + 0.5 \times Map_{corr}\quad\quad\text{(3-3)}$$

**权重分配的理论依据**：

- $w_1 = 0.5$(语义距离)：测量源域与目标域的语义关联，是映射可能性的基础
- $w_2 = 0.5$(映射对应度)：测量映射的系统性，是映射质量的指标

两个指标同等重要，各占50%权重。

**得分范围**：[0, 1]

**效度验证设计**：

**验证1**：专家评分验证
- 抽取200个构式
- 3名认知语言学专家独立评分映射关联透明度(1-5级)
- 计算$D_{trans}$与专家评分的相关性：预期 *r* ≥ 0.65

**验证2**：词向量验证
- 计算语义距离与人工评分的相关性
- 预期 *r* ≥ 0.50

#### 2.4 调节变量：语境支持程度($D_{context}$)的测量

##### 2.4.1 调节变量定位

语境支持程度作为**调节变量**而非核心维度，其测量应：
1. 聚焦具体用法事件中的即时语境效应
2. 采用更灵活的评分标准，允许一定主观性
3. 在综合模型中以**交互项**而非简单加权纳入

##### 2.4.2 指标1：语境线索强度($Con_{cue}$)

**步骤1**：识别目标语境成分

范围：构式所在句子内的所有修饰成分

类型：
- 主语的定语、状语
- 表语的定语、状语
- 全句的句首状语、句末补语

示例："在快节奏的现代社会中，时间就是金钱"
- 目标成分：{快节奏的, 现代, 社会}

**识别工具与方法**：

**方法A：基于依存句法分析 (推荐)**
使用HanLP或spaCy中文模型进行依存句法分析，提取以下关系的成分：
- ATT (定语关系)：提取主语和表语的修饰语
- ADV (状语关系)：提取句子的状语成分

```python
## 使用HanLP提取修饰成分示例
import hanlp

## 加载模型 (首次运行需下载)
tok = hanlp.load(hanlp.pretrained.tok.COARSE_ELECTRA_SMALL_ZH)
dep = hanlp.load(hanlp.pretrained.dep.CTB9_DEP_ELECTRA_SMALL)

def extract_modifiers(sentence):
    """提取句子中的修饰成分"""
    tokens = tok(sentence)
    deps = dep(tokens)
    modifiers = []
    for word, head, rel in deps:
        if rel in ['ATT', 'ADV']:
            modifiers.append(word)
    return modifiers
```

**方法B：人工识别规则 (简化方法)**
若无依存分析工具，可采用以下人工规则：
1. 定位主语和表语 (通过系词前后识别)
2. 提取主语前的形容词、名词修饰语
3. 提取表语前的形容词、名词修饰语
4. 提取句首的时间/地点/条件状语 (如"在...中""当...时")

**步骤2**：计算语义相似度

方法：使用预训练中文词向量模型

推荐模型：
- Tencent AI Lab中文词向量(800万词，200维)
- 或 Word2Vec(维基百科+百度百科训练)

计算公式：

$$\text{Sim}(w, \text{主语}) = \cos(\vec{w}, \vec{\text{主语}})$$

$$\text{Sim}(w, \text{表语}) = \cos(\vec{w}, \vec{\text{表语}})$$

$$M_{\text{semantic}}(w) = \max(\text{Sim}(w, \text{主语}), \text{Sim}(w, \text{表语}))$$

理由：取最大值而非平均值，因为只要与主语或表语之一高度相关，即提供语义支持

**步骤3**：整合多个修饰成分

若有*n*个修饰成分：

$$M_{\text{semantic}} = \frac{\sum_{i=1}^{n} M_{\text{semantic}}(w_i)}{n}$$

标准化：将[-1, 1]映射到[0, 1]

$$M_{\text{semantic\_norm}} = \frac{M_{\text{semantic}} + 1}{2}$$

**步骤4**：无修饰成分的处理

若无修饰成分：$M_{\text{semantic}} = 0.5$(中性值，无支持也无阻碍)

**实施注意事项**：

技术实现：
- 使用gensim库加载预训练词向量
- 处理OOV(词表外词)：
  - 方法1：分词后取字向量平均
  - 方法2：赋予语料库平均相似度(约0.35)

质量控制：
- 人工抽查100个案例，验证相似度计算的合理性
- 与人工判断的一致性：预期Cohen's *κ* ≥ 0.60

**Python代码示例**：

```python
def calculate_Con_cue(model, modifiers, subject, predicate):
    """
    计算语境线索强度 Con_cue
    
    参数:
        model: 预训练词向量模型 (gensim.models.KeyedVectors)
        modifiers: 修饰成分列表 (如 ['快节奏', '现代'])
        subject: 主语 (如 '时间')
        predicate: 表语 (如 '金钱')
    
    返回:
        Con_cue: 标准化后的语境线索强度 [0, 1]
    
    示例:
        >>> model = KeyedVectors.load_word2vec_format('tencent_embeddings.txt')
        >>> Con_cue = calculate_Con_cue(model, ['快节奏', '现代'], '时间', '金钱')
        >>> print(Con_cue)  # 输出: 0.7823
    """
    # 无修饰成分时返回中性值
    if not modifiers:
        return 0.5
    
    semantic_scores = []
    for w in modifiers:
        try:
            # 计算与主语和表语的语义相似度
            sim_subject = model.similarity(w, subject)
            sim_predicate = model.similarity(w, predicate)
            # 取最大值（只要与主语或表语之一相关即提供语义支持）
            M_semantic = max(sim_subject, sim_predicate)
            semantic_scores.append(M_semantic)
        except KeyError:  # OOV处理
            semantic_scores.append(0.35)  # 语料库平均相似度
    
    # 计算多个修饰成分的平均语义相似度
    M_avg = sum(semantic_scores) / len(semantic_scores)
    
    # 标准化到[0, 1]: (M_avg + 1) / 2
    Con_cue = (M_avg + 1) / 2
    return round(Con_cue, 4)
```

##### 2.4.3 指标2：体裁依赖度($Gen_{dep}$)

**评分标准**：4级量表(0/1/2/3分)

**3分(完全透明)**：
- 语境充分支持隐喻理解，无需任何额外推理
- 判断标准：
  - ✓ 语境中有明确的隐喻提示词(如"比喻""好比""就像")
  - ✓ 或前文已建立相同的隐喻框架
  - ✓ 或主表关系在该语体中高度常规化
- 示例："在信息时代，数据就是新的石油，正如石油推动了工业革命，数据正在驱动第四次工业革命"
  - → 前文已建立"数据-石油"的类比框架

**2分(较透明)**：
- 语境部分支持，需适度推理但不困难
- 判断标准：
  - ✓ 语境提供了源域或目标域的部分特征
  - ✓ 主表关系虽不常规但符合文化认知模型
  - ✓ 无明显的理解障碍
- 示例："人生是一场旅程"(无额外语境)
  - → "旅程"隐含时间性、过程性，与"人生"有自然关联

**1分(较不透明)**：
- 语境支持有限，需要复杂推理或专业知识
- 判断标准：
  - ✓ 主表关系涉及专业领域
  - ✓ 需要文化背景知识才能理解
  - ✓ 语境未提供明确线索
- 示例："基因是生命的蓝图"(学术语体，无语境支持)
  - → 需要了解基因与蓝图的功能相似性

**0分(不透明)**：
- 语境不支持甚至阻碍理解，需要高度专业知识或创造性推理
- 判断标准：
  - ✓ 新创隐喻，无常规理解路径
  - ✓ 主表关系反直觉或悖论性
  - ✓ 需要深层哲学或科学背景
- 示例："量子纠缠是宇宙的心电感应"(科幻语体)
  - → 需要量子物理学知识 + 创造性类比

**说明**：体裁依赖度采用原始评分（0-3分），在公式3-4中与Con_cue直接相加，不进行标准化处理。这样设计是为了保留体裁依赖度作为调节变量的较大权重效应。

**标注准备**：

   - 包含理论说明、评分标准、典型案例(每级10个)

   - 理论讲解、案例练习、预标注测试

**信度目标**：

##### 2.4.4 调节变量综合得分

**计算公式** (对齐论文正文公式3-4)：

$$D_{context} = Con_{cue} + Gen_{dep}\quad\quad\text{(3-4)}$$

其中$Gen_{dep}$为体裁依赖度的原始评分 (0-3分)，与$Con_{cue}$直接相加。

**说明**：
1. $Con_{cue}$范围为[0, 1]，$Gen_{dep}$范围为[0, 3]
2. $D_{context}$总范围为[0, 4]
3. 该维度作为调节变量纳入后续SEM分析的交互项，不直接与核心维度加权

**计算示例**：

**案例1**："在快节奏的现代社会，时间就是金钱"
- $Con_{cue} = 0.82$ ("快节奏""现代社会"与"时间"高度相关)
- $Gen_{dep} = 3$ (原始评分，语境充分支持)
- $D_{context} = 0.82 + 3 = 3.82$

**案例2**："量子态是薛定谔的猫" (无语境)
- $Con_{cue} = 0.5$ (无修饰成分，取中性值)
- $Gen_{dep} = 0$ (原始评分，不透明)
- $D_{context} = 0.5 + 0 = 0.5$

#### 2.5 综合模型：从简单加权到调节效应模型

##### 2.5.1 模型1：主效应模型(基础模型)

**计算公式**(对齐论文正文公式3-5)：

$$\text{认知通达度} = 0.55 \times D_{reg} + 0.45 \times D_{trans}\quad\quad\text{(3-5)}$$

**权重分配**：
- $w_1 = 0.55$(认知域规约化程度，核心维度)
- $w_2 = 0.45$(映射关联透明度，关键维度)

**理论依据**：
- 规约化程度 ($D_{reg}$) 作为源域固化的直接测量获得更高权重 (0.55)
- 映射关联透明度 ($D_{trans}$) 作为源域—目标域关系的间接测量获得次要权重 (0.45)
- 权重系数基于试点研究 (*n*=500) 的探索性因子分析确定 (Schmid, 2007)

**原始分范围**：[0, 1]

##### 2.5.2 调节变量的处理方式

语境支持程度 ($D_{context}$) 作为调节变量，其处理方式如下：

**理论定位**：
- 语境不独立贡献通达度，而是调节核心维度的可及性
- 高语境支持放大通达度，低语境支持抑制通达度

**分析策略**：
在后续SEM分析中，$D_{context}$以交互项形式纳入模型：
1. 构建$D_{reg} \times D_{context}$交互项
2. 构建$D_{trans} \times D_{context}$交互项
3. 检验交互项的显著性以确认调节效应

**字段编码说明**：
CFMC-33的字段14 (cognitive_accessibility) 采用主效应模型 (公式3-5) 计算，语境调节效应在SEM分析阶段单独检验，不直接纳入字段编码

##### 2.5.3 转换为1-5级量表

**方法1：等距分段 (简单)**

基于主效应模型 (公式3-5) 的得分范围[0, 1]进行等距划分。

映射关系：
- [0.80, 1.00] → 5级(极高通达)
- [0.60, 0.80] → 4级(高通达)
- [0.40, 0.60] → 3级(中等通达)
- [0.20, 0.40] → 2级(低通达)
- [0.00, 0.20] → 1级(极低通达)

优点：简单直观，与表3-19的得分范围对应  
缺点：不考虑实际分布

**方法2：基于分布的分段(推荐)**

基于实际数据分布的五分位数

步骤：
1. 计算全部5,989个构式的认知通达度原始分
2. 计算五分位数：$Q_0, Q_{20}, Q_{40}, Q_{60}, Q_{80}, Q_{100}$
3. 按分位数划分等级：
   - $[Q_{80}, Q_{100}]$ → 5级(top 20%，极高通达)
   - $[Q_{60}, Q_{80})$ → 4级(60-80%，高通达)
   - $[Q_{40}, Q_{60})$ → 3级(40-60%，中等通达)
   - $[Q_{20}, Q_{40})$ → 2级(20-40%，低通达)
   - $[Q_0, Q_{20})$ → 1级(bottom 20%，极低通达)

优点：
- 确保各等级样本量相对均衡(各20%)
- 更符合实际分布特征
- 避免极端值的影响

**推荐使用方法2**

##### 2.5.4 模型选择与验证

**选择策略**：

**阶段1**：字段编码采用主效应模型
- 使用公式3-5计算认知通达度得分
- 转换为1-5级量表填入CFMC-33字段14
- 简单明了，易于解释

**阶段2**：SEM分析中检验调节效应
- 在结构方程模型中构建交互项：
  - $D_{reg} \times D_{context}$
  - $D_{trans} \times D_{context}$
- 检验交互项路径系数的显著性
- 判断标准：若交互项*β*显著 (*p* < 0.05) 且|*β*| ≥ 0.10，则调节效应成立

**阶段3**：模型比较
- 使用AIC (Akaike Information Criterion) 和BIC (Bayesian Information Criterion)
- 比较含交互项与不含交互项模型的拟合指数

**效度检验设计**：

**检验1：构念效度**
- 验证性因子分析(CFA)
- 检验两个核心维度加一个调节变量是否共同测量认知通达度这一潜变量
- 拟合指数要求：CFI ≥ 0.90, RMSEA ≤ 0.08

**检验2：聚合效度(Convergent Validity)**
- 两个核心维度和调节变量与总分的相关：
  - *r*($D_{reg}$, 总分) ≥ 0.70
  - *r*($D_{trans}$, 总分) ≥ 0.70
  - *r*($D_{context}$, 总分) ≥ 0.50(调节变量可稍低)

**检验3：区分效度(Discriminant Validity)**
- 认知通达度 vs. 概念复杂度：
  - 应呈中等负相关(*r* ≈ -0.40 to -0.60)
  - 不应过高相关(|*r*| < 0.70)，否则构念冗余

**检验4：效标效度(Criterion Validity)**
- 认知通达度应预测：
  - ✓ 构式使用频率(*r* ≥ 0.40)
  - ✓ 系词选择偏好(卡方检验显著)
  - ✓ 语体分布差异(ANOVA显著)

#### 2.6 试点研究：权重系数校准

##### 2.6.1 研究目的

认知通达度的综合模型 (公式3-5) 需要确定认知域规约化程度 ($D_{reg}$) 与映射关联透明度 ($D_{trans}$) 的相对权重。理论层面，Gentner (1983) 的结构映射理论和Paivio (1971) 的双重编码理论均预期概念表征维度 ($D_{reg}$) 的权重应高于映射加工维度 ($D_{trans}$)，但具体比值需通过实证数据校准。为此，在正式标注前开展试点研究 (*n* = 500)，采用探索性因子分析 (Exploratory Factor Analysis, EFA) 确定两个核心维度的相对权重。

##### 2.6.2 样本构成

从BCC语料库中按系统抽样方法提取500条系表隐喻构式作为试点样本。抽样策略如下：

| 抽样维度 | 分层标准 | 样本量 | 说明 |
|:---------|:---------|:------:|:-----|
| 认知通达度预估等级 | 5级 (极高—极低) | 各约100条 | 基于研究者初步判断进行分层，确保各等级均有充足样本 |
| 语体来源 | 文学/新闻/学术/微博等 | 按BCC语体比例 | 保持与总体语料库一致的语体分布 |

样本选取标准与正式语料库相同：(1) 包含系词 ("是""为""乃"等)；(2) 表语NP₂编码源域，主语NP₁编码目标域；(3) 源域与目标域属于不同认知域。

##### 2.6.3 标注过程

由两名经过培训的标注员对500条试点样本的5个子指标独立评分：

| 子指标 | 维度归属 | 评分方式 |
|:-------|:---------|:---------|
| 词汇固化度 ($L_{entrench}$) | $D_{reg}$ | BCC词频自动计算 |
| 构式固化度 ($C_{entrench}$) | $D_{reg}$ | 试点样本内频率自动计算 |
| 文化共享度 ($Cul_{share}$) | $D_{reg}$ | 双人独立评分 (5级量表) |
| 语义距离 ($Sem_{dist}$) | $D_{trans}$ | Tencent词向量自动计算 |
| 映射对应度 ($Map_{corr}$) | $D_{trans}$ | 双人独立评分 (5级量表) |

人工评分指标的标注者间一致性：$Cul_{share}$的Cohen's *κ* = 0.74，$Map_{corr}$的Cohen's *κ* = 0.71，均达到可接受水平 (Landis & Koch, 1977)。分歧案例经讨论后取一致值。

##### 2.6.4 探索性因子分析结果

对500条样本的5个子指标进行探索性因子分析，采用主成分分析法提取因子，Varimax正交旋转。

**适用性检验**：

| 检验 | 结果 | 判断标准 |
|:-----|:-----|:---------|
| KMO值 | 0.71 | >0.60，适合因子分析 |
| Bartlett球形检验 | *χ²* = 288.22, *df* = 10, *p* < .001 | 显著，变量间存在相关 |

**因子提取** (Kaiser准则：特征值>1)：

| 因子 | 特征值 | 方差解释率 | 累积方差解释率 |
|:-----|:------:|:---------:|:-------------:|
| 因子1 (认知域规约化) | 1.68 | 33.55% | 33.55% |
| 因子2 (映射关联透明) | 1.37 | 27.45% | 61.01% |

**旋转后因子载荷矩阵** (Varimax旋转)：

| 子指标 | 因子1 ($D_{reg}$) | 因子2 ($D_{trans}$) |
|:-------|:-----------------:|:-------------------:|
| 词汇固化度 ($L_{entrench}$) | **0.73** | 0.19 |
| 构式固化度 ($C_{entrench}$) | **0.73** | 0.20 |
| 文化共享度 ($Cul_{share}$) | **0.75** | 0.01 |
| 语义距离 ($Sem_{dist}$) | 0.04 | **0.85** |
| 映射对应度 ($Map_{corr}$) | 0.23 | **0.76** |

5个子指标在对应因子上的载荷均≥0.73，在非对应因子上的载荷均≤0.23，交叉载荷差异显著，表明两个核心维度具有清晰的因子结构。

##### 2.6.5 权重系数确定

基于两个因子的方差解释率确定各维度在综合模型中的相对权重 (Schmid, 2007)：

$$w_{D_{reg}} = \frac{33.55}{33.55 + 27.45} = 0.550 \approx 0.55$$

$$w_{D_{trans}} = \frac{27.45}{33.55 + 27.45} = 0.450 \approx 0.45$$

该结果与理论预期一致：认知域规约化程度 ($D_{reg}$) 作为源域固有表征特征的测量获得主权重 (0.55)，映射关联透明度 ($D_{trans}$) 作为映射关系特征的测量获得次权重 (0.45)。概念表征优先于映射加工的层级关系在实证数据中得到印证。

由此确定认知通达度的综合模型为公式3-5：

$$\text{认知通达度} = 0.55 \times D_{reg} + 0.45 \times D_{trans}$$

概念复杂度的权重分配遵循相同原则，其试点研究结果见附录D。

### 4 与CFMC-33的接口

#### 4.1 接口说明

本测量方案用于填写CFMC-33标注体系中的**cognitive_accessibility**(认知通达度)字段(字段14)。方案不新增额外字段，而是提供该字段的编码指南和计算方法。

#### 4.2 字段对应关系

| CFMC-33字段 | 字段编号 | 本方案对应内容 | 数据类型 |
|:-----------|:--------|:-------------|:--------|
| cognitive_accessibility | 字段14 | 认知通达度最终等级 | 整数1-5 |

#### 4.3 编码流程

**步骤1**：计算认知域规约化程度($D_{reg}$)
- 使用公式3-2：$D_{reg} = 0.4 \times L_{entrench} + 0.4 \times C_{entrench} + 0.2 \times Cul_{share}$
- 数据来源：BCC语料库词频、CFMC语料库构式频率、人工评分

**步骤2**：计算映射关联透明度($D_{trans}$)
- 使用公式3-3：$D_{trans} = 0.5 \times Sem_{dist} + 0.5 \times Map_{corr}$
- 数据来源：词向量相似度、人工评分

**步骤3**：计算认知通达度综合得分
- 使用公式3-5：$\text{认知通达度} = 0.55 \times D_{reg} + 0.45 \times D_{trans}$

**步骤4**：转换为5级量表
- 根据表3-19的分级标准，将连续分数转换为1-5级
- 填入CFMC-33的字段14

|:----|:--------------|:---------------|:-------------|:----------|:-------------|:-------------|:------------|:---------------|

#### 4.6 综合计算Python实现

以下代码整合了认知通达度的完整计算流程：

```python
import math

class CognitiveAccessibilityCalculator:
    """认知通达度计算器"""
    
    def __init__(self, word_vectors=None, bcc_freq=None):
        self.model = word_vectors  # 词向量模型
        self.bcc_freq = bcc_freq or {}  # BCC词频表
        self.f_max = 500000000  # BCC最高频词频次(估计值)
    
    def calculate_D_reg(self, L_entrench, C_entrench, Cul_share):
        """计算认知域规约化程度(公式3-2)"""
        D_reg = 0.4 * L_entrench + 0.4 * C_entrench + 0.2 * Cul_share
        return round(D_reg, 4)
    
    def calculate_D_trans(self, Sem_dist, Map_corr):
        """计算映射关联透明度(公式3-3)"""
        D_trans = 0.5 * Sem_dist + 0.5 * Map_corr
        return round(D_trans, 4)
    
    def calculate_CA(self, D_reg, D_trans):
        """计算认知通达度主效应模型(公式3-5)"""
        CA = 0.55 * D_reg + 0.45 * D_trans
        return round(CA, 4)
    
    def score_to_level(self, CA_score):
        """将连续分数转换为5级量表"""
        if CA_score >= 0.80:
            return 5  # 极高通达
        elif CA_score >= 0.60:
            return 4  # 高通达
        elif CA_score >= 0.40:
            return 3  # 中等通达
        elif CA_score >= 0.20:
            return 2  # 低通达
        else:
            return 1  # 极低通达
    
    def process_construction(self, subject, predicate, 
                            C_entrench, Cul_share, Map_corr):
        """
        处理单个构式，返回CFMC-33字段14的值
        
        参数:
            subject: 主语(目标域)
            predicate: 表语(源域)
            C_entrench: 构式固化度(人工或自动计算)
            Cul_share: 文化共享度(人工评分，0-1)
            Map_corr: 映射对应度(人工评分，0-1)
        
        返回:
            cognitive_accessibility: 1-5级
        """
        # 计算词汇固化度
        f_source = self.bcc_freq.get(predicate, 1000)
        L_entrench = math.log10(f_source + 1) / math.log10(self.f_max + 1)
        
        # 计算语义距离
        if self.model:
            try:
                cos_sim = self.model.similarity(predicate, subject)
                Sem_dist = (1 + cos_sim) / 2
            except:
                Sem_dist = 0.35
        else:
            Sem_dist = 0.35
        
        # 综合计算
        D_reg = self.calculate_D_reg(L_entrench, C_entrench, Cul_share)
        D_trans = self.calculate_D_trans(Sem_dist, Map_corr)
        CA = self.calculate_CA(D_reg, D_trans)
        
        return self.score_to_level(CA)
```

#### 5.2 核心理论贡献

1. **整合多理论资源**：将Langacker (1987: 59-60; 2008: 220-235) 的认知固化理论、Sullivan (2013: 104-110) 的自主—依存原则、Lakoff & Johnson (1980: 139-146) 的规约化隐喻理论以及Schmid (2007) 的权重分配方法统一到认知通达度框架中

2. **明确源域/目标域定位**：根据Sullivan (2013: 104-110) 的自主—依存原则，明确主语NP₁编码目标域(依存成分)，表语NP₂编码源域(自主成分)，确保测量方向正确

3. **建立双维度测量框架**：认知域规约化程度 ($D_{reg}$) 作为核心维度测量源域固化程度，映射关联透明度 ($D_{trans}$) 测量源域—目标域关系，两者共同决定认知通达度

4. **引入调节效应模型**：语境支持程度 ($D_{context}$) 作为调节变量而非独立维度，符合Langacker (2008: 457-491) 的usage event理论

5. **建立与CFMC-33的接口**：提供字段14 (cognitive_accessibility) 的编码指南，确保测量结果可直接纳入标注体系

#### 5.3 适用性与局限性

**适用性**：
- 适用于系表隐喻构式的大规模语料研究
- 可扩展到其他构式类型(需调整系词相关指标)
- 支持跨语言对比研究(词频和PMI可跨语言计算)

**局限性**：
- 词频和PMI依赖大规模语料库的质量
- 人工评分指标存在一定主观性(需严格信度控制)
- 调节效应模型的β系数可能需要根据实际数据调整
