📚 隐喻构式认知框架（CFMC）

本研究以 Sullivan (2013) 隐喻构式理论 为核心主干，针对其应用于汉语系词构式时的理论盲点进行三向整合：

  • 借鉴Langacker (1987, 2008) 认知语法：认知参照点模型、侧显/基底机制 → 支撑 Q3
  • 整合Goldberg (1995, 2006) 构式网络理论：四类链接关系、构式网络拓扑 → 支撑 Q2
  • 聚焦汉语类型学特征：零系词现象、话题突出特征 → 贯穿 Q1-Q3

元认知原则：认知分工原则 + 具身锚定需求

⚠️ 句法层面与隐喻层面的区分

分析汉语系表隐喻构式时，需区分两个不同层面的认知分析：

层面 理论来源 NP₁功能 NP₂功能
句法层面 Langacker (2008) 认知参照点R（射体/主语） 目标T（界标/表语）
隐喻层面 Sullivan (2013) 自主元素，唤起目标域 依存元素，唤起源域

维度互补关系：句法加工（时间维度）从NP₁→NP₂建立关系；概念映射（逻辑维度）用NP₂（源域）理解NP₁（目标域）。两个层面互补而非冲突。

理论框架：Sullivan主干 + 三向整合

🎯 三个研究问题

三个研究问题形成"核心递进+横向扩展"的关系结构：Q1与Q3共享Sullivan自主-依存原则，构成认识论递进主线；Q2基于Q1类型划分横向扩展至网络视角。

Q1: 类型体系

汉语系表隐喻构式呈现哪些类型及其特征？

📖 四阶段认知编码机制（PLS-SEM形成性模型）

本研究将Sullivan (2013) 的两步分析程序深化为四阶段机制，以PLS-SEM形成性测量模型进行验证：

  • 阶段1 (η₁)：认知域激活——源域频率+目标域频率+具身体验（形成性指标）
  • 阶段2 (η₂)：参照点锚定——认知通达度+常规度+原型距离（形成性指标）
  • 阶段3 (η₃)：跨域映射——映射方向+系统性+蕴涵丰富度（形成性指标）
  • 阶段4 (Y)：语言编码——系词功能（单指标）

三模型比较：

  • 模型A（四阶段）：GoF=0.2585，β₁/β₂/γ三条路径，全部显著***
  • 模型B（缩减）：GoF=0.2593，去除η₁，仅η₂→η₃→Y
  • 模型C（扩展）：GoF=0.2670，增加η₁→η₃直接路径β₃=0.111***

H3-1验证：GoF=0.2585>0.25，全部路径显著; PLS-MGA 3/3组拟合成功 → 支持

H1-1验证：认知通达度与概念复杂度相关性分析

📊 验证结果

Pearson r = -0.5354***，Spearman ρ = -0.5269***（p < 0.001）

双维度呈现强负相关（r=-0.5354, R²=28.67%），验证了认知分工原则：高通达度源域倾向于与低复杂度目标域配对，效应量达到大效应标准。

H1-1判定：✓ 支持

Q2: 网络组织

汉语系表隐喻构式网络呈现怎样的内部组织特征？

📖 理论背景

本章运用 Goldberg (1995, 2006) 构式网络理论，分析构式间的关联模式。

四类链接关系：隐喻扩展链接、多义链接、实例链接、子部分链接

核心假设H2：构式网络呈现小世界性质（C ≥ 0.60，L ≤ 3.0，σ > 1），体现语言使用者以最小认知代价组织和提取构式知识的认知效率原则。

H2验证：小世界网络性质检验

指标符号判断标准随机网络基准观测值结论
聚类系数 C ≥ 0.60 0.5871 0.75 ✓ 通过
平均路径长度 L ≤ 3.0 1.4324 1.4242 ✓ 通过
小世界系数 σ > 1.0 1.0 (定义) 1.2847 ✓ 通过

📊 计算公式与结论

σ = (C/C_random) / (L/L_random) = (0.75/0.5871) / (1.4242/1.4324) ≈ 1.28

三项指标均通过阈值检验（C=0.75≥0.60, L=1.42≤3.0, σ=1.28>1），H2判定：✓ 支持——汉语系表隐喻构式网络符合小世界网络特征。

理论意义：小世界性质表明构式网络兼具高聚类（语义相近构式形成局部簇）与短路径（任意构式可快速关联）特征，体现认知效率原则。

Q3: 认知机制

汉语系表隐喻构式的认知编码机制是什么？

📖 四阶段认知编码机制

本研究将Sullivan (2013) 的两步分析程序深化为四阶段机制，以PLS-SEM路径模型进行验证：

  • 阶段1 (η₁)：认知域激活——激活源域和目标域（完整模型含此阶段）
  • 阶段2 (η₂)：参照点锚定——建立规约性、认知通达度、原型距离的锚定结构
  • 阶段3 (η₃)：跨域映射——Sullivan核心，含映射方向、系统性、蕴涵丰富度
  • 阶段4 (Y)：语言编码——映射关系预测系词功能选择

PLS-SEM形成性测量模型：

  • η₁（认知域激活）：source_domain_num, target_domain_num
  • η₂（参照点锚定）：conventionality, cognitive_accessibility, prototype_distance
  • η₃（跨域映射）：mapping_direction, systematicity, entailment_richness
  • Y（语言编码）：copula_function

核心假设H3-1：GoF=0.2585，全部路径显著（β₂=-0.712***为核心路径）；PLS-MGA 3/3组成功拟合

📌 H1-2b"不支持"的理论解释

为何LDA准确率偏低？

LDA判别分析的低准确率（41.46%）并非分类体系的失败，而是原型范畴模糊边界特征的必然反映。 根据Rosch（1978）原型范畴理论，自然范畴的边界本质上是模糊的，类型之间存在渐变而非截然分明的界限。

  • 类型内部高凝聚：GMM轮廓系数0.9722证明类型内部结构紧密
  • 类型边界模糊：LDA低准确率反映类型间的渐变过渡
  • 混淆模式系统性：混淆主要发生在相邻通达度类型之间
理论启示

这一发现与认知语言学的连续性假说高度一致：语言范畴不是离散的， 而是沿着原型性维度呈梯度分布。LDA的"失败"恰恰验证了：

1. 12类分类是理论驱动——基于认知分工原则，而非纯统计优化

2. LDA是辅助验证——核心证据来自GMM内部凝聚+原型梯度显著

3. 模糊边界有认知意义——便于语言使用者灵活处理边缘情况

四阶段认知编码机制在三类系词功能构式中普遍成立，且路径系数均高度显著。不同系词功能组在路径强度上存在差异（置换检验），反映认知加工的类型特异性。

组间差异的认知解释
  • identificational构式：η₁→η₂路径最强（β=0.411），需要更多域激活来锚定参照点
  • attributive构式：η₂→η₃路径最强（β=0.725），锚定对映射的预测力最大
  • equative构式：整体路径强度居中，认知加工模式介于两者之间
