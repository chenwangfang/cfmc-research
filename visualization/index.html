📚 隐喻构式认知框架（CFMC）

本研究以 Sullivan (2013) 隐喻构式理论 为核心主干，针对其应用于汉语系词构式时的理论盲点进行三向整合：

  • 借鉴Langacker (1987, 2008) 认知语法：认知参照点模型、侧显/基底机制 → 支撑 Q3
  • 整合Goldberg (1995, 2006) 构式网络理论：四类链接关系、构式网络拓扑 → 支撑 Q2
  • 聚焦汉语类型学特征：零系词现象、话题突出特征 → 贯穿 Q1-Q3

元认知原则：认知分工原则 + 具身锚定需求

⚠️ 句法层面与隐喻层面的区分

分析汉语系表隐喻构式时，需区分两个不同层面的认知分析：

层面 理论来源 NP₁功能 NP₂功能
句法层面 Langacker (2008) 认知参照点R（射体/主语） 目标T（界标/表语）
隐喻层面 Sullivan (2013) 自主元素，唤起目标域 依存元素，唤起源域

维度互补关系：句法加工（时间维度）从NP₁→NP₂建立关系；概念映射（逻辑维度）用NP₂（源域）理解NP₁（目标域）。两个层面互补而非冲突。

理论框架：Sullivan主干 + 三向整合

🎯 三个研究问题

三个研究问题形成"核心递进+横向扩展"的关系结构：Q1与Q3共享Sullivan自主-依存原则，构成认识论递进主线；Q2基于Q1类型划分横向扩展至网络视角。

Q1: 类型体系

汉语系表隐喻构式呈现哪些类型及其特征？

📖 理论背景

双维度分类体系基于Sullivan (2013) 自主-依存原则构建：

  • 认知通达度（3级：高/中/低）：测量源域的认知激活便利性，即源域概念的规约化程度与映射透明度
  • 概念复杂度（4类映射类型）：测量目标域概念化所需的认知资源，通过映射方向操作化

核心假设H1-1：认知通达度与概念复杂度呈显著负相关（r ≈ -0.40至-0.60），体现"常规-简单"与"创新-复杂"的认知分工原则

H1-1验证：认知通达度与概念复杂度相关性分析

📊 验证结果

Pearson r = -0.5433***，Spearman ρ = -0.5478***（p < 0.001）

双维度呈现显著负相关，验证了认知分工原则：高通达度源域（规约化常规隐喻）倾向于与低复杂度目标域配对，形成"常规-简单"与"创新-复杂"的认知分工。

H1-1判定：✓ 支持

H1-2验证：12类构式类型分布

📊 分布特征

高通达类构式占比85.61%（5,127条），是主体类型；中通达类占比12.37%（741条）；低通达类仅占2.02%（121条）

最大类型：高通达_具抽（T10）占36.57%，体现"具体→抽象"映射的核心地位

H1-2c验证：原型梯度结构

📊 梯度结构

中心成员：61.71%（3,696条）| 次中心成员：38.22%（2,289条）| 边缘成员：0.07%（4条）

ANOVA检验：F = 45.89***，p < 0.001，η² = 0.015，三组间差异显著

H1-2c判定：✓ 支持——12类构式呈现清晰的原型梯度结构

H1-2a/b验证：GMM聚类与LDA判别

📝 说明

GMM聚类表现优异（轮廓系数0.9676远超阈值0.30），验证了12类构式分类的统计效度。

LDA判别准确率41.81%未达85%标准，但这反映了构式类型间的"模糊边界"特性，符合原型理论预期——类型间存在渐变过渡而非截然分明。

Q2: 网络组织

汉语系表隐喻构式网络呈现怎样的内部组织特征？

📖 理论背景

本章运用 Goldberg (1995, 2006) 构式网络理论，分析构式间的关联模式。

四类链接关系：隐喻扩展链接、多义链接、实例链接、子部分链接

核心假设H2：构式网络呈现小世界性质（C ≥ 0.60，L ≤ 3.0，σ > 1），体现语言使用者以最小认知代价组织和提取构式知识的认知效率原则。

H2验证：小世界网络性质检验

Q3: 认知机制

汉语系表隐喻构式的认知编码机制是什么？

📖 四阶段认知编码机制

本研究将Sullivan (2013) 的两步分析程序深化为四阶段机制，以SEM路径模型进行验证：

  • 阶段1 (η₁)：认知域激活——激活源域和目标域的认知域基础
  • 阶段2 (η₂)：参照点锚定——建立稳定的认知锚定结构
  • 阶段3 (η₃)：跨域映射——Sullivan核心原则，建立跨域映射关系
  • 阶段4 (X₁₁)：语言编码——映射关系决定系词功能选择

SEM测量模型（CFMC-33指标变量）：

  • η₁：embodied_experience, source_domain, target_domain
  • η₂：conventionality, cognitive_accessibility, prototype_distance
  • η₃：mapping_direction, mapping_basis, systematicity, entailment_richness
  • Y：copula_function（η₃的结果观测变量）

核心假设H3-1：四阶段机制得到验证（CFI > 0.90），且12类构式共享同一因子结构（弱不变性ΔCFI < 0.01）

📌 H1-2b"不支持"的理论解释

为何LDA准确率偏低？

LDA判别分析的低准确率（41.81%）并非分类体系的失败，而是原型范畴模糊边界特征的必然反映。 根据Rosch（1978）原型范畴理论，自然范畴的边界本质上是模糊的，类型之间存在渐变而非截然分明的界限。

  • 类型内部高凝聚：GMM轮廓系数0.9676证明类型内部结构紧密
  • 类型边界模糊：LDA低准确率反映类型间的渐变过渡
  • 混淆模式系统性：混淆主要发生在相邻通达度类型之间
理论启示

这一发现与认知语言学的连续性假说高度一致：语言范畴不是离散的， 而是沿着原型性维度呈梯度分布。LDA的"失败"恰恰验证了：

1. 12类分类是理论驱动——基于认知分工原则，而非纯统计优化

2. LDA是辅助验证——核心证据来自GMM内部凝聚+原型梯度显著

3. 模糊边界有认知意义——便于语言使用者灵活处理边缘情况

📌 弱不变性"未通过"的理论解释

两层检验的区分

✓ 形态不变性通过（11/12组收敛）

→ 12类构式共享相同的因子结构（三潜变量模型）

✗ 弱不变性未通过（ΔCFI=0.023 > 0.01）

→ 因子载荷在12类构式间存在显著差异

这意味着：同一个认知机制，不同的加工强度。 12类构式都使用相同的四阶段认知编码框架，但各阶段的"贡献权重"因构式类型而异。

认知解释
  • 高通达类型：加工自动化程度高，各阶段"压缩"为整体模式，载荷趋于均衡
  • 低通达类型：需要更多认知资源，各阶段更显性化，载荷分布更分散
  • 类型特异性：不同隐喻类型激活四阶段机制的侧重点不同

方法论启示：

采用部分测量不变性策略（Byrne et al., 1989）： 释放载荷差异最大的指标约束，保留核心路径的可比性。 这是认知范畴研究中的常见做法，因为认知加工本身具有情境敏感性。
